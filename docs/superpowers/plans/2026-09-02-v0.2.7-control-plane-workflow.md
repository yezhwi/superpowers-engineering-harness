# v0.2.7 Control-Plane Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement task ownership, finding-aware review recovery, evidence command separation, deterministic Gate preflight, release readiness, and auditable complexity review.

**Architecture:** Extend existing `controlplane.py` command routing and existing domain modules. Keep artifact validation in schemas/domain helpers; use `transaction.publish` for multi-artifact writes. Do not split `controlplane.py` merely for naming.

**Tech Stack:** Python 3.11, PyYAML, jsonschema, pytest.

**Spec:** `docs/Superpowers-Engineering-Harness-v0.2.7-实施规格.md`

## Global Constraints

- Preserve Q1/FAST default flow.
- Preserve Git binding, workspace fingerprint freshness, and finding lifecycle.
- Never modify `.harness/history/**` during migration.
- New user-facing failures require stable error codes.
- Run one spec Step only; report GREEN/BLOCKED and await user before next Step.
